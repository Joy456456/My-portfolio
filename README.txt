PUBLISH WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new repository (a public repository is simplest for a free GitHub Pages site).
3. Upload index.html to the repository's root.
4. Open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for GitHub Pages to publish the website.

CONNECT YOUR NICNAMES DOMAIN
1. In repository Settings -> Pages, enter your exact domain under Custom domain and save.
2. In NicNames, open DNS management for that domain.
3. Follow GitHub's current official guide for the correct DNS records:
   https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site
4. Do not delete existing DNS records for email or other services unless you know they are unnecessary.
5. After DNS resolves, enable Enforce HTTPS in GitHub Pages settings if available.
